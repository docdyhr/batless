# Releases

batless is published to three channels:

- **crates.io**: `cargo install batless`
- **GitHub Releases**: prebuilt binaries for Linux (glibc and musl), macOS (Intel and Apple Silicon), and Windows at <https://github.com/docdyhr/batless/releases>
- **Homebrew**: `brew install docdyhr/tap/batless`

See [CHANGELOG.md](CHANGELOG.md) for what changed in each version, and [docs/PUBLISHING.md](docs/PUBLISHING.md) for how releases are cut and published.
